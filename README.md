A responsive personal portfolio built with plain HTML, CSS and JavaScript.

- About, skills, projects, education and certifications
- GitHub and LinkedIn links
- Contact section
- Mobile navigation
- Updated CGPA: **7.65 / 10**

## Run locally
Open `index.html` in a browser.

## Push to GitHub

Create a new GitHub repository, for example `charishma-portfolio`, then run:

```bash
cd charishma-portfolio
git init
git add .
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/charishma906/charishma-portfolio.git
git push -u origin main
```

## Deploy with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/root`.
5. Save.
6. GitHub will provide the live portfolio URL.

Before publishing, verify your phone number and email are correct and that you are comfortable making them public.
